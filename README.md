# 🚀 TalentHub API

API REST desenvolvida em Spring Boot para gestão de talentos e projetos.

🔗 **Repositório:** https://github.com/vanguimaraes14-coder/talenthub-API
🌐 **GitHub Pages:** https://vanguimaraes14-coder.github.io/talenthub-API/

### 🛠️ Tecnologias
- Java 17+
- Spring Boot 3
- MySQL
- Maven
- Postman

### 📁 Estrutura
- `src/` - Código fonte da API
- `database/talenthub.sql` - Script do banco de dados
- `postman/` - Coleção para testes
